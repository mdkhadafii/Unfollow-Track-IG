# Security Policy

## Supported versions

Security fixes are provided for the latest code on the `main` branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. If private vulnerability reporting is available for this repository, use **Security → Advisories → Report a vulnerability**. Otherwise, contact the repository owner through their GitHub profile. Do not open a public issue with an exploitable vulnerability.

Include the affected commit or version, a concise description of impact, and reproduction steps using synthetic data. Do not send Instagram exports, passwords, verification codes, cookies, access tokens, or other personal information.

The project maintainer will acknowledge reports and coordinate a fix and disclosure timeline with the reporter.
